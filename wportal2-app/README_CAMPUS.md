# Campus Link — 金沢大学の授業評価・学生マッチングサイト

> **サークル機能更新：** 口コミ投稿数・性格タイプの2ランキングと活動投稿への画像添付を追加しました。最新の仕様と追加マイグレーション・GD設定は[サークル機能ガイド](../document/CAMPUS_CLUBS.md)を参照してください。

金沢大学の学生が、授業の情報や口コミを共有し、自分と共通点のある先輩に履修の相談ができるWebアプリです。既存のwportal2環境に、独立した学生向け画面とアカウントを追加しています。

**サイトURL：<http://localhost:9190/campus>**

このURLはDockerを起動している自分のパソコンで使います。インターネット上に公開されたURLではありません。チームメンバーもコードを取得して各自の環境で起動します。Gitでコードを共有しても、ローカルDBの学生アカウントや投稿は共有されません。

本書は現在の実装に基づく利用・開発ガイドです。性格診断の種類など、今後変更する予定の仕様もあります。

## できること

| 機能 | 現在の動作 |
| --- | --- |
| 学生登録・ログイン | メールアドレスとパスワードで登録・ログイン |
| プロフィール | 表示名、学域・学類、学年、サークル、性格タイプを登録・変更 |

| レーダーチャート | 5項目の評価平均を授業ごとに表示 |

## 起動方法

### 既に環境構築が済んでいる場合

1. Macの「アプリケーション」からDocker Desktopを起動します。
2. Mac側のターミナルで、`docker-compose.yml`があるリポジトリ直下へ移動します。

この作業環境での移動先は次のとおりです。チームメンバーは自分の保存場所に読み替えてください。

```bash
cd /Users/imamuramasato/Downloads/wportal2
```

3. コンテナを起動します。

```bash
docker compose up -d
```

4. Campus Linkのマイグレーションを順番に適用します。既に適用済みの場合はスキップされます。

```bash
docker exec wportal2_web php artisan migrate --path=database/migrations/2026_09_13_000000_create_campus_tables.php
docker exec wportal2_web php artisan migrate --path=database/migrations/2026_09_13_010000_add_details_to_campus_reviews.php
```

5. ブラウザで <http://localhost:9190/campus> を開きます。

**Campus Linkの画面には`npm run dev`は不要です。** HTMLをLaravel Blade、見た目を静的CSSで表示しています。既存の勤怠画面などは別の構成です。

### 初めて環境を構築する場合

Docker、`.env`、Composerなどの基本準備は[既存の環境構築README](README.md)を参照し、その後、上記のCampus Link用マイグレーションを適用してください。

- `.env`の場所は`wportal2-app/.env`です。既存の設定ファイルを上書きしないでください。
- `composer install`はコンテナ内で実行します。Mac側からは`docker exec wportal2_web composer install`でも実行できます。
- Campus Linkの認証にはGoogleの認証キーを使いません。既存のGoogleログインとは別の学生アカウントを新規登録します。
- Campus Linkには授業・学生のサンプルデータ投入処理はありません。最初は新規登録と投稿から始めます。
- 既存READMEの`TestCaseSeeder`はCampus Linkの学生アカウントを作成するものではありません。
- 現在の教材欄はテキスト入力で、Campus LinkのためのMinIOバケット作成やファイルアップロード設定は不要です。

### ターミナルの使い分け

本書の`docker exec wportal2_web ...`はMac側から実行するコマンドです。`root@...#`と表示されているときはコンテナ内なので、`exit`でMac側に戻ってから実行します。

`npm run dev`が動いているときに終了するには、Control + Cで停止してから`exit`を入力します。

## 画面一覧と使い方

| 画面 | URL | 用途 |
| --- | --- | --- |
| 入口・授業一覧 | <http://localhost:9190/campus> | 未ログインならログイン画面へ移動 |
| 新規登録 | <http://localhost:9190/campus/register> | 学生アカウントの作成 |
| ログイン | <http://localhost:9190/campus/login> | メール・パスワード認証 |
| 授業一覧 | <http://localhost:9190/campus/courses> | 検索・口コミ閲覧・評価投稿 |
| 教授一覧 | <http://localhost:9190/campus/professors> | 教授名と担当授業の検索・閲覧 |
| 先輩一覧 | <http://localhost:9190/campus/matches> | 共通点のある先輩を探す |
| メッセージ | <http://localhost:9190/campus/messages> | 会話相手の選択・DM送受信 |
| サークル | <http://localhost:9190/campus/clubs> | サークル情報の閲覧・投稿 |
| プロフィール | <http://localhost:9190/campus/profile> | 自分の登録情報の変更 |

登録・ログイン以外の画面はログインが必要です。

### 1. 学生登録

表示名、メールアドレス、パスワード、学域・学類、学年を入力します。

- パスワード：10〜128文字。確認用の入力と一致する必要があります。
- 学年：1〜6年。
- サークル：任意、120文字以内。未所属の場合は空欄にできます。
- 性格タイプ：任意。現在は16タイプから登録できます。
- 大学：金沢大学固定。

表示名や学年、学域・学類、サークル、性格タイプは他の利用者に表示されます。メールアドレスは他の学生向け画面には表示しません。大学メールによる在籍確認は行っていません。

### 2. 授業を探して口コミを読む

検索欄に授業名または教授名を入力し「検索」を押します。授業カードに5項目の平均評価が表示され、「口コミを読む」を開くと受講情報を確認できます。投稿者への相談リンクからDM画面へ進めます。

教授ページは、投稿された教授名と担当授業をまとめた一覧です。大学公式の教員プロフィールや経歴は登録されていません。

### 3. 授業の評価を投稿する

授業一覧の「＋ 授業の評価を投稿」を押して投稿フォームへ移動し、下記の項目を入力します。授業がまだ登録されていなくても、最初の評価投稿と同時に授業情報が作成されます。

## 授業投稿の項目

「名前」は現在、**授業名**として実装しています。投稿者の名前はログイン中のプロフィールから自動表示します。教授検索のため、教授名も入力します。

| 項目 | 必須 | 入力内容 |
| --- | --- | --- |
| 名前（授業名） | 必須 | 120文字以内 |
| 教授名 | 必須 | 80文字以内 |
| 学部・学域 | 必須 | 対象授業の学部・学域、120文字以内 |
| 学科・学類 | 必須 | 対象授業の学科・学類、120文字以内 |
| レーダーチャート用評価 | 必須 | 下記5項目をそれぞれ1〜5で評価 |
| 出席方法 | 必須 | 学生証の読み取り、出席票、確認なし等。200文字以内 |
| 課題の量 | 必須 | 1：ほとんどない／2：少ない／3：普通／4：多い／5：とても多い |
| リモート割合 | 必須 | 0〜100の整数。0%は全て対面、100%は全てリモート |
| 教材 | 必須 | 教科書名や配布資料等、2,000文字以内。不要なら「なし」 |
| 補足・口コミ | 任意 | 授業の感想や履修のアドバイス、2,000文字以内 |

教材はテキスト情報です。PDF・画像などの添付やアップロードには対応していません。

同じ大学・授業名・教授名を同じ授業として扱い、学生1人につき1件の評価を保存します。同じ授業に再投稿すると自分の評価が更新され、元の作成日時は維持されます。別の名前で投稿すると別授業になるため、チームで表記を揃えてください。

投稿の学部・学科は対象授業の情報で、プロフィールの学域・学類とは別に保存します。追加項目がなかった時点の投稿は「未登録」と表示します。

## レーダーチャートの仕様

| 評価軸 | 5の意味 |
| --- | --- |
| わかりやすさ | とてもわかりやすい |
| おもしろさ | とてもおもしろい |
| 単位の取りやすさ | とても取りやすい |
| 負担の軽さ | とても負担が軽い |
| おすすめ度 | とてもおすすめ |

同じ授業に投稿された各評価の平均をサーバーで計算し、SVGの五角形チャートと数値一覧に表示します。数値一覧は小数第1位までです。

**「課題の量」は5ほど多く、「負担の軽さ」は5ほど軽い評価です。** 別々の項目なので連動して変換しません。出席方法・教材・リモート割合は各口コミの詳細として表示し、チャートの評価軸には含めません。

## 先輩マッチングの仕様

同じ大学に所属し、自分より学年が上の学生が対象です。次の共通点を加算し、高い順に表示します。

| 共通点 | 点数 |
| --- | --- |
| 同じ大学 | 25点 |
| 同じプロフィールの学域・学類 | 30点 |
| 同じサークル | 20点 |
| 同じ性格タイプ | 25点 |
| 合計 | 最大100点 |

学域・学類、サークル、性格タイプは登録値の完全一致で判定します。空欄は加点しません。スコアはプロフィールの共通点の目安で、性格の相性を科学的に診断する値ではありません。

先輩カードで共通点と授業投稿を確認し、「先輩に相談する」からDMを送れます。

## DMとサークル投稿

### DM

- 先輩だけでなく、同じ大学の他の学生にも送信できます。
- 1件あたり2,000文字以内です。
- 自分自身や別大学の学生を宛先に指定できません。
- アプリ上の会話は送信者と受信者だけが閲覧できます。DMはDBに保存されます。
- 新着はページの再読み込みで確認します。リアルタイム更新・既読・通知・ブロックは未実装です。

### サークル

- 学生アカウントでログインした利用者が投稿できます。
- サークル名は120文字以内、活動・募集情報は10〜2,000文字です。
- サークル名は会津大学公式一覧から事前登録され、プロフィールと活動・募集投稿では新しいサークルを追加できません。
- 公式サークルのカテゴリ・タグ・連絡先情報・紹介画像の編集には `CAMPUS_CLUB_EDIT_PASSWORD` が必要です。紹介画像は1団体1枚で、選択すると差し替わります。活動・募集投稿の編集は未実装です。

## 技術構成

| 分野 | 使用内容 |
| --- | --- |
| Webサーバー | Docker内のApache |
| バックエンド | PHP 8.3系・Laravel 12系 |
| 画面 | Laravel Blade、HTML、静的CSS |
| グラフ | SVGで描画 |
| 開発DB | MySQL 8.0 |
| 認証 | Laravelセッション、ハッシュ化パスワード |
| テスト | PHPUnit、メモリ内SQLite |

既存リポジトリにはReact・Inertia・Vite・GraphQLもありますが、Campus Linkの画面とフォームはBladeで実装しています。Campus専用のJSON APIはありません。

処理の流れは次のとおりです。

```text
ブラウザ
  ├─ GET → routes/campus.php → PageController → 検索サービス → DB
  │                                            ↓
  │                          Bladeのページ・部品 → HTMLを返す
  └─ POST → 認証・CSRF・入力チェック → 機能別Controller → 保存 → リダイレクト
```

URL、フォームのname属性、ビューに渡す変数がフロントとバックエンドの接点です。詳細は[受け渡し仕様書](document/CAMPUS_CONTRACT.md)を参照してください。

## ファイル構成と担当範囲

以下は`wportal2-app/`内の構成です。

```text
app/
├─ Campus/                       検索・保存・マッチング・共通定義
├─ Http/Controllers/Campus/       機能別のリクエスト処理
├─ Http/Requests/Campus/          授業投稿の入力チェック
└─ Http/Middleware/CampusAuthenticate.php  学生ログイン確認
routes/campus.php                Campus専用のURL定義
resources/views/campus/
├─ layout.blade.php              共通レイアウト
├─ pages/                        授業・教授・認証・先輩・DM・サークル画面
└─ components/                   投稿フォーム・カード・チャートなど
public/
├─ campus.css                    CSS読み込みの入口
└─ campus-assets/                機能別CSS
    ├─ base.css                  ボタン・入力欄など共通デザイン
    ├─ layout.css                画面配置・レスポンシブ対応
    ├─ courses.css               授業・評価・投稿詳細
    ├─ messages.css              DM
    ├─ matches.css               マッチング
    └─ profile.css               プロフィール
database/migrations/            Campus用テーブル作成・項目追加
tests/Feature/Campus/           機能テスト
```

| 担当 | 主に変更する場所 |
| --- | --- |
| フロント | `resources/views/campus/`、`public/campus-assets/` |
| バックエンド | `app/Campus/`、Campus用Controller・Request・Middleware、DB、テスト |
| 共通・調整が必要 | ルート、共通レイアウト、共通CSS、受け渡し仕様書 |

ファイルごとの説明は[チーム開発ガイド](document/CAMPUS_TEAM.md)にあります。特に次の場所から編集すると担当を分けやすくなります。

- 投稿フォーム：`resources/views/campus/components/review-form.blade.php`
- 投稿詳細：`resources/views/campus/components/review-detail.blade.php`
- チャートの見た目：`resources/views/campus/components/radar-chart.blade.php`
- 評価平均・授業検索：`app/Campus/CourseCatalog.php`
- 投稿の入力ルール：`app/Http/Requests/Campus/StoreReviewRequest.php`
- 投稿保存：`app/Campus/ReviewWriter.php`
- マッチング条件：`app/Campus/StudentMatches.php`

**CSS用に`public/campus/`というフォルダを作らないでください。** `/campus`という画面URLと衝突し、Apacheがフォルダを開こうとして403になるためです。静的ファイルは`public/campus-assets/`へ置きます。

## データベース

| テーブル | 保存するもの |
| --- | --- |
| `campus_students` | 学生プロフィール、メール、パスワードハッシュ |
| `campus_courses` | 大学・授業名・教授名 |
| `campus_reviews` | 投稿者・授業・5評価・学部学科・受講情報・口コミ |
| `campus_club_catalog` | 公式サークル名・カテゴリ・タグ・連絡先・ホームページ・紹介画像 |
| `campus_clubs` | サークル名・内容・投稿者 |
| `campus_messages` | 送信者・受信者・本文 |

学生は複数の評価やサークル投稿を持ち、授業には複数の学生の評価が紐づきます。DMは送信者・受信者の学生IDを持ちます。

マイグレーションは次の2つです。

1. `2026_09_13_000000_create_campus_tables.php`：5つのテーブルを作成。
2. `2026_09_13_010000_add_details_to_campus_reviews.php`：学部学科・出席方法・課題量・リモート割合・教材を追加。
3. `2026_09_14_020000_create_campus_club_catalog.php`：公式サークル一覧39件を登録。
4. `2026_09_14_030000_add_images_to_campus_club_catalog.php`：公式サークル紹介画像の保存項目を追加。

チームで項目を追加するときは、新しいマイグレーションを作ります。適用済みファイルの書き換えや`migrate:refresh`での再構築を通常の更新手順にしないでください。追加マイグレーションなら既存投稿を残して更新できます。

## テストと動作確認

Mac側のターミナルで実行します。

```bash
docker exec wportal2_web php artisan test tests/Feature/Campus
```

| ファイル | 確認内容 |
| --- | --- |
| `AuthTest.php` | 登録・ログイン・ログアウト・未ログイン時の画面制限 |
| `ReviewTest.php` | 投稿保存・更新・検索・チャート・追加項目・数値範囲・作者の保護・旧投稿表示 |
| `CommunityTest.php` | 先輩表示・DMの閲覧制限・サークル投稿 |
| `ClubTest.php` | 公式一覧外の投稿拒否・編集パスワード・公式画像の登録・差し替え・ランキング・画像投稿 |
| `CampusTestCase.php` | 専用のメモリ内DBを準備する共通処理 |

このテストは専用のメモリ内SQLiteを使います。ローカルMySQLの投稿を初期化しません。

テストではLaravel内の処理を確認します。ApacheのURL処理や実際のブラウザ表示は、別に次の手順で確認します。

1. `/campus`から登録・ログインできること。
2. 授業を投稿し、各項目と評価チャートが表示されること。
3. 同じ授業を再投稿すると自分の評価が更新されること。
4. 通常ウィンドウとプライベートウィンドウで異なる学年の2アカウントを使い、先輩表示とDMを確認すること。
5. 送受信者以外のアカウントではその会話が見えないこと。
6. サークル投稿が一覧に表示されること。

```bash
git add README_CAMPUS.md
git diff --cached --stat
git commit -m "Document Campus Link features and development setup"
git push
```

`git push`で追跡先が未設定と表示されたら、`git push -u origin 自分のブランチ名`を使います。実装ファイルが未共有なら、READMEだけではアプリは動かないため、実装も共有してください。`.env`や認証キーはコミットせず、差分を確認してから送信します。

## 困ったとき

| 表示・症状 | 確認と対応 |
| --- | --- |
| `failed to connect to the docker API` | Docker Desktopが起動しているか確認する |
| `no configuration file provided` | `docker-compose.yml`があるリポジトリ直下へ移動する |
| コンテナが見つからない・停止している | リポジトリ直下で`docker compose ps`、必要なら`docker compose up -d` |
| `vendor/autoload.php`がない | `docker exec wportal2_web composer install`を実行する |
| `campus_*`テーブルや追加カラムがない | 「起動方法」にある2つのマイグレーションを適用する |
| `/campus`がApacheの403 Forbiddenになる | `public/campus/`が残っていないか確認。CSSは`public/campus-assets/`へ置く |
| 見た目が古い・CSSが反映されない | MacのブラウザでCommand + Shift + R。CSS読み込み先も確認する |
| 投稿時に入力エラーになる | 画面上部のエラーと必須項目・文字数・数値範囲を確認する |
| 419エラー | ログイン画面を再読み込みし、再ログインする。フォームに`@csrf`があるか確認する |
| 検索結果や先輩が表示されない | 授業投稿や自分より上の学年の学生が登録されているか確認する |
| 他のメンバーのPCで投稿が見えない | 各自のローカルDBは別。コード共有とデータ共有は別の作業 |

原因が分からないときは、開いたURL、実行したコマンド、エラーメッセージをチームに共有します。

## 未実装の機能

現在はローカル開発用の初期版です。次の機能はまだ実装していません。

- 大学メール認証・在籍確認、パスワード再設定。
- 質問形式の性格診断、確定した性格診断方式。
- 大学公式の授業・教授データの取り込み、シラバス連携。
- 活動・募集投稿の編集専用画面、通報、管理者向け管理画面。
- 教材ファイル・画像・PDFのアップロード。
- DMのリアルタイム更新、通知、既読、ブロック。
- サークル代表者の権限管理、サークル専用ログイン。
- 大量データ向けのページネーション。
- 一般公開用サーバーへのデプロイ。
