# Campus Link（ローカル開発版）

> **バックエンド仕様更新：** 対象大学を会津大学へ変更し、授業投稿のDB項目を更新しました。[最新のDB・受け渡し仕様](CAMPUS_REVIEW_DB.md)を参照してください。以下の従来の投稿項目・大学名の説明は旧仕様です。画面の新仕様対応はフロント担当との統合作業として残っています。

金沢大学向けの授業評価・学生マッチングアプリ。

サイトの詳細は [Campus Link README](../README_CAMPUS.md) を参照してください。

## 起動

既存のDocker環境で次を実行する。既存のGoogle認証とは別の学生アカウントを使用する。

```bash
docker compose up -d
docker exec wportal2_web php artisan migrate --path=database/migrations/2026_09_13_000000_create_campus_tables.php
docker exec wportal2_web php artisan migrate --path=database/migrations/2026_09_13_010000_add_details_to_campus_reviews.php
```

http://localhost:9190/campus を開き、新規登録する。この画面はLaravel BladeとCSSで描画するため、npm run devは不要。

## 利用の流れ

1. 表示名、メール、10文字以上のパスワード、学域・学類、学年を登録。大学は金沢大学固定。
2. サークルと性格タイプは任意。プロフィール画面から変更可能。性格診断方式は未確定で、現在は16タイプの結果入力のみ。
3. 授業名・教授名、学部学科、5項目の評価、出席方法、課題の量、リモート割合、教材を投稿。補足の口コミは任意。
4. 授業・教授を検索し、平均値のレーダーチャートと口コミを見る。同じ授業・教授への再投稿は自分の評価を更新。
5. 上級生の共通点スコアと投稿を閲覧し、DMで相談。
6. ログイン済みの学生がサークルの活動・募集情報を投稿。

マッチングは同じ大学25点、同じ学類30点、同じサークル20点、同じ性格タイプ25点。空欄は加点しない。相性の科学的診断ではない。
DMは送受信者だけに表示される。新着は手動再読み込み。サークル投稿には学生アカウントのパスワードログインを使用し、サークル共有パスワードは設けていない。

## 確認

```bash
docker exec wportal2_web php artisan test tests/Feature/Campus
```

専用のメモリ内SQLiteで検証し、既存のデータは変更しない。2つの学生アカウントを異なる学年で作り、別ブラウザまたはプライベートウィンドウを使うと先輩表示とDMを確認できる。

## 現段階の範囲

ローカル向けの初期実装。授業・教授の公式データ取り込み、大学メール認証、パスワード再設定、投稿削除・通報・管理画面、DMの通知・ブロック、ページネーションは未実装。教授情報は学生が投稿した名前と担当授業を表示する。実際の学籍確認は行っていないため、一般公開前に認証・運用機能の追加が必要。
