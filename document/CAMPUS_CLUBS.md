# 公式サークル一覧・ランキング・画像投稿

`/campus/clubs` に以下の2タブを追加しています。

- **口コミ投稿数ランキング**：現在所属している学生による授業・教授の口コミの累計順。`campus_reviews` をリクエストごとに `COUNT` し、カウンターは保存しません。授業と教授の画面で共用する口コミを二重に数えません。同じ授業への更新は1件のまま、削除した口コミは集計から外れます。同数の場合は口コミの作成日時が新しい順、さらに同じ場合はサークル名順です。
- **あなたに似ているサークル**：`?tab=similarity`。診断登録者のうちログイン学生と同じ性格タイプの人の割合順。同率の場合は上記の口コミ順です。診断登録者がいないサークルは末尾に「未登録」として表示します。自分の診断が未登録の場合はプロフィール登録への案内を表示します。

今回、直近30日間や1人あたりの投稿数は採用していません。

## 公式サークルの固定一覧

会津大学の[公式サークル・自治機関一覧](https://web-ext.u-aizu.ac.jp/circles/c-jichi/members/)から、団体名39件とカテゴリ・タグを `campus_club_catalog` に初期登録します。

- プロフィールの所属サークルと活動・募集投稿のサークル名は、公式一覧からの選択式です。
- サーバー側でもマスタに存在する団体名だけを受け付けるため、未登録のサークルをフォーム改変で追加することはできません。
- 公式マスタにない旧データは新しい一覧には表示されません。新しい団体を追加する場合は、マイグレーションの一覧を更新します。
- 各団体のカテゴリ・タグ・連絡先URL・ホームページURL・紹介画像は、画面の「サークル情報を編集」から変更できます。編集には環境変数 `CAMPUS_CLUB_EDIT_PASSWORD` のパスワードが必要です。パスワードはDBへ保存せず、未設定の場合は編集できません。

## 所属と診断の保存・集計

- 同じ大学に所属する学生のみ対象です。口コミの授業も同じ大学のものに限ります。
- 公式マスタの全団体を一覧に含め、`campus_students.circle`（任意・1サークル）とサークル投稿の `name` を同名で紐づけます。同名の活動投稿は1つのサークルにまとめ、最新の投稿と折りたたみ式の過去投稿を表示します。
- 所属・投稿の名前は画面の選択肢から登録します。表記ゆれの統合、所属の承認、複数サークルへの所属はこの実装には含みません。
- 所属変更時は、その学生の過去の口コミも新しい所属先で集計します。投稿時の所属履歴は保存していません。
- 診断結果は既存の `campus_students.personality` に16タイプのいずれか、または `NULL` を保存します。回答内容は保存せず、診断自体はサイト内で行いません。
- サークルごとに登録メンバー数、診断登録人数、未登録人数、タイプ別人数・割合を表示します。割合の分母は**診断登録人数**です。タイプが同じ人の割合であり、性格の相性を保証する指標ではありません。
- 集計はメンバー、診断タイプ、口コミ、活動投稿、画像を別々に取得して結合し、投稿や画像の枚数による人数・口コミ数の水増しを防ぎます。

## 公式サークルの紹介画像

- 公式サークルごとに1枚の紹介画像を登録できます。登録済みの画像がある場合、新しい画像を選ぶと差し替わります。
- 編集フォームは `multipart/form-data` で、フィールド名は `image` です。JPEG / PNG / WebP、最大5MiB、最大1,600万画素に対応します。
- 画像は長辺1600px以下へ縮小して専用の非公開ディスクへ保存し、同じ大学のログイン済み利用者だけが `GET /campus/club-catalog-images/{catalog}` で閲覧できます。
- 画像の保存に失敗した場合や差し替え時は、不要になったファイルを片付けます。

## サークルの活動・募集投稿への画像添付

- `POST /campus/club` は `multipart/form-data`、フィールド名は `images[]`。画像なしの従来の投稿も可能です。
- JPEG / PNG / WebP、1枚最大5MiB、最大4枚、画像1枚につき最大1,600万画素です。ファイル内容の形式をサーバーでも検証し、GDで読み込めない画像は拒否します。
- 長辺1600px以下へ縦横比を維持して縮小し、小さい画像は拡大しません。GDで再エンコードするため元画像の付加メタデータは引き継ぎません。アニメーションは静止画になります。
- 保存名はUUID。ファイルは専用ローカルディスク `campus_clubs` の `storage/app/private/campus-clubs` に保存し、DBの `campus_club_images` には保存キー・MIME・縦横サイズ・投稿IDだけを保存します。公開シンボリックリンクやMinIO設定は不要です。
- `GET /campus/club-images/{image}` は学生ログインと同じ大学の確認を行い、認証済みユーザーに画像を返します。公開URLではありません。
- 投稿フォームには選択プレビューと枚数・容量・形式のチェックがあります。入力エラー後は画像を再選択します。
- 投稿者だけが `DELETE /campus/club/{club}` で自分の投稿と画像を削除できます。画面では削除欄を開いてから実行します。添付画像の差し替えは投稿を削除して再投稿します。
- アップロード途中やDB保存失敗時は保存済み画像を片付けます。ストレージ削除障害はLaravelログへ報告します。通常の削除経路外（手動SQLでの削除など）の画像掃除は別途必要です。
- ローカル保存ディレクトリはDBと一緒にバックアップしてください。複数Webサーバーで運用する場合は共有ストレージへの切り替えが必要です。

## 環境への適用

WebコンテナにGD（JPEG・PNG・WebP対応）と、4枚分のリクエストを受け取る25MiBの `post_max_size` を追加しています。他の開発環境ではリポジトリ直下から実行してください。

```bash
docker compose build wportal2_web
docker compose up -d wportal2_web
docker exec wportal2_web php artisan migrate --path=database/migrations/2026_09_14_010000_add_campus_club_images_and_ranking_index.php
docker exec wportal2_web php artisan migrate --path=database/migrations/2026_09_14_020000_create_campus_club_catalog.php
docker exec wportal2_web php artisan migrate --path=database/migrations/2026_09_14_030000_add_images_to_campus_club_catalog.php
```

既存のCampus用マイグレーションが適用済みであることが前提です。公式一覧テーブル、活動投稿画像、公式サークル紹介画像、所属検索用インデックスを追加し、既存の口コミや診断結果は書き換えません。`.env` に `CAMPUS_CLUB_EDIT_PASSWORD`（10文字以上）を設定してから編集機能を使用してください。チーム共通の値は以下です（ローカル開発環境専用・本番相当の環境では別の値を使用してください）。

```
CAMPUS_CLUB_EDIT_PASSWORD=campus-club-2026
```

```bash
docker exec -e XDEBUG_MODE=off wportal2_web php artisan test tests/Feature/Campus
```

テストはメモリ内SQLiteとテスト専用の画像ディスクを使います。`ClubTest` は公式一覧外の投稿拒否、編集パスワード、公式サークル紹介画像の登録・差し替え、ランキング順、集計の重複防止、プロフィール変更、未診断・空データ、画像3形式の縮小、枚数・容量・形式制限、大学・投稿者の権限、削除、保存失敗時の後片付けを確認します。
